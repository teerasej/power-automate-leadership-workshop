## ผลงานปลายวัน

- หนึ่งโอกาสที่มีเหตุผลรองรับ
- Workflow Blueprint ที่เห็นบทบาท ข้อมูล ข้อยกเว้น และจุดตรวจของคน
- Leadership Handover Card สำหรับเริ่มบทสนทนากับทีมปฏิบัติการ

## ก่อนเริ่ม

- กิจกรรมใช้ post-it ปากกา และกระดาษแผ่นใหญ่ กลุ่มละ 4–6 คนเป็นค่าเริ่มต้น
- ไม่ต้องมีบัญชี Power Automate หรือ paid software licence ผู้เรียนไม่ต้องสร้าง Flow ในระบบ
- ใช้ข้อมูลสมมติที่เตรียมไว้ หรือกระบวนการทั่วไปที่ไม่มีข้อมูลส่วนบุคคลและข้อมูลลับ
- ตัวเลขและหลักฐานในกรณีศึกษาเป็นข้อมูลสมมติ ใช้เพื่อฝึกคิดเท่านั้น
