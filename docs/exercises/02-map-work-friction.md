# Exercise 2: Map work and friction

<ExerciseModuleHeader :module="2" />

<CourseProgress :current="2" />

Think of a kitchen with orders waiting at different stations. Before choosing equipment, find where work stops and who is waiting for whom.

**Time:** 10:45–11:55

> **Licence:** This paper activity requires no paid software licence or Power Automate account.

## Preparation

- Work in groups of 4–6 with sticky notes, pens, and large paper. Assign recorder, timekeeper, and spokesperson roles.
- Open the [case pack](/resources/case-pack) and [worksheets](/resources/worksheets).
- Use your observations from Exercise 1. Use fictional or non-confidential context only.
- Use ordinary sticky notes for the current process. Save the Flow cards for Exercise 4, after selecting an opportunity.

## Practice 1: Map the current process (15 minutes) {#practice-1}

**Primary target:** Create a current-process map that makes handovers visible.

**Learner output:** A 5–8-step current-process map in Worksheet 2.

Check [the current process](/resources/case-pack#current-process) and, together as a group, discuss and draw the map accurately.

1. Agree where the process starts and ends. Record this in Worksheet 2.
2. Write one action on each sticky note, such as check details, request review, or notify the requester.
3. Arrange 5–8 steps and name the responsible role under each step.
4. At every handover, record the information or status received and the information or status passed to the next role.
5. Read the map from start to finish.
6. Discuss any unclear handovers or missing information with the group.

### Checkpoint

The map has 5–8 steps, a start, an end, a responsible role for every step, and information or status at every handover.



## Practice 2: Identify friction with evidence (15 minutes) {#practice-2}

**Primary target:** Explain where work encounters friction and how it affects the process.

**Learner output:** At least three evidence-linked friction markers on the current-process map.

1. Mark relevant steps **(R) Repeated work**, **(W) Waiting**, **(M) Missing information**, or **(U) Unclear owner**. Use this guide:
	1. Write **(R) Repeated work** when someone repeats the same action or enters the same information more than once.
	2. Write **(W) Waiting** when the next action is known, but work cannot continue until a person responds or an agreed time arrives.
	3. Write **(M) Missing information** when a required detail, document, or status is not available.
	4. Write **(U) Unclear owner** when no role has agreed responsibility for the next action.
2. Use general observations you may share. Label assumptions clearly.
3. Explain who is affected and what happens, such as re-entering information or being unable to notify the requester.
4. Distinguish routing problems from problems that first need clearer rules or responsibilities.

### Checkpoint

At least three friction points have an impact

## Practice 3: Choose three pain points to compare (5 minutes) {#practice-3}

**Primary target:** Produce a clear shortlist for prioritisation.

**Learner output:** Three named pain points, A–C, that point to specific locations on the map.

1. Choose three points from the map. Name each using the pattern: what work gets stuck, and where?
2. Record them as A, B, and C in the sticky notes, put them on the map where the friction occurs.
3. Use [fictional evidence for comparing pain points](/resources/case-pack#fictional-evidence-for-comparing-pain-points) to check
4. Keep the map visible.

### Checkpoint

Each pain point points back to a specific place on the map.


## Playground activity: Explore a task from your work

**Primary target:** Apply the mapping method to a task that the group finds boring or painful.

**Learner output:** One selected task with a current-process map, friction markers, and three pain points.

1. Each group member thinks of 3 tasks from their work that feel boring, repetitive, or painful.
2. Write each task on a separate sticky note. Each person contributes three sticky notes.
3. Place all the sticky notes on one flipchart. Briefly explain each task to the group without including confidential information.
4. Give each group member one vote. Vote for the task that looks most painful and most worth exploring for automation.
5. Select the task with the most votes. If there is a tie, discuss the tied tasks and vote again.
6. Repeat Practice 1 with the selected task: map its current process from start to end, including roles and handovers.
7. Repeat Practice 2 with the selected task: mark at least three friction points and add evidence, impact, or an open question.
8. Repeat Practice 3 with the selected task: choose and label three pain points, A–C, on the map.

### Checkpoint

The group has selected one task and created a map with roles, handovers, friction evidence, and three clearly located pain points. Treat the task as an automation candidate, not a confirmed solution.

## Summary

Your map explains the problem before proposing a solution. Use this evidence to select one opportunity in Exercise 3.
